# Career Street 3D Game

An interactive Three.js game route that turns the portfolio content into a walkable street. The blocky character can walk past buildings where signs show the site information: intro, work history, education, and contact details.

## Run Locally

```bash
bun install
bun dev
```

Open `http://localhost:8080/game`.

Use `WASD` or the arrow keys to move. On small screens, use the on-screen movement buttons.
